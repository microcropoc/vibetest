# vt-72 — Генерация курса через LM Studio

## Контекст

Есть вкладка «Генерация промта» (копирование промта для внешнего LLM) и «Импорт». Нужен прямой вызов LM Studio из приложения с сохранением профилей подключения.

## Цель

Вкладка **«Генерация курса»**: описание курса, выбор или ввод профиля (URL, ключ, модель), генерация JSON и автоматический импорт при успешной валидации. Профили редактируются в **Настройках**.

## Требования

- Профиль: название, base URL, API key, model; хранение в `settings` ключ `llmProfiles`
- Настройки: список, добавление, правка, удаление; ключ в списке маскирован
- Генерация: тот же промт, что «Генерация промта»; OpenAI-compatible `POST …/chat/completions`
- Успех: импорт с новыми id, ссылка на курс
- Ошибки: сырой ответ + ошибки импорта; курс не сохраняется
- Отмена запроса во время генерации

## Технические заметки

- `course-generation/`, `settings/` (профили), `storage/settings-repository`
- Переиспользовать `buildCourseGenerationPrompt`, `unwrapJsonImportText`, `CourseImportService`
