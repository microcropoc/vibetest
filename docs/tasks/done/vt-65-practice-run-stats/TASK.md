# vt-65 — Статистика прогона практики (JS, SQL, regex)

## Цель

После запуска практики показывать, сколько тестов пройдено из общего числа. При успешном прохождении — суммарное время выполнения решения пользователя и эталона в сравнении.

## Требования

- Fail-fast без изменений: при провале «пройдено» = `failedTestIndex`, всего = `tests.length`.
- Время только при успехе, сумма по всем кейсам; измерять в воркере только код под проверкой (JS chain, SQL query, regex test).
- Статистика транзиентная (`practiceFeedback`), не в progress.

## Критерии готовности

- Три типа шагов: сообщения воркера, раннеры, UI.
- SPEC: параграф «Статистика прогона».
- `ng test --watch=false` зелёный.
