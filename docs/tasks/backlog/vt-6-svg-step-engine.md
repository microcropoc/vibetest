# vt-6 — Движок шага `svg` (без UI)

## Контекст

Шаг svg — объект с inline `svg`; без автопроверки, завершение как у theory. Рендер — **vt-21** (доверенный контент, без санитизации в MVP).

## Цель

Доменный движок svg: валидация уже на уровне курса (Zod); локальное состояние просмотра, complete по advance, retry; тесты.

## Требования

- Соответствие `$defs/svgContent` (обязательный `svg`, опционально caption/description).
- Поведение завершения/retry — как theory (vt-4), переиспользовать helpers vt-3 где возможно.
- **Не** реализовывать санитизацию, DOM, `<script>`/URL блокировку — только домен «отметил просмотр».
- Тесты без TestBed.

## Технические заметки

- Зависимости: **vt-3**, **vt-2**; опционально переиспользование паттерна vt-4.
- Без inline SVG preview в тестах (достаточно fixture-объекта content).
