# vt-77 — Сообщение об успехе в quiz

## Контекст

В quiz-шаге плеера после проверки показывается только сообщение об ошибке; верный ответ никак не подтверждается (в практике есть «Все проверки пройдены.»).

## Цель

После верного ответа в quiz видно сообщение «Верно! Шаг пройден.».

## Требования

- Сообщение показывается, если шаг `completed`, последняя проверка не провалена и текущий выбор совпадает с верным ответом.
- Видно и при возврате к пройденному шагу (выбор сохранён в черновике).
- Пропадает при смене выбора и после «Повторить» (выбор очищается).
- Ошибка имеет приоритет над успехом.

## Технические заметки

- `player/` — чистая функция `quizShowsSuccess` рядом с `practice-step-view.ts`; `quiz-step-ui` получает `showSuccess` через `input()`.
