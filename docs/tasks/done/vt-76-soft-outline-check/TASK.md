# vt-76 — Мягкая проверка плана и усиленный промт

## Контекст

Небольшие модели в LM Studio часто возвращают план, где в модулях нет шагов `theory`, `svg` или `quiz`. Поэтапная генерация (vt-74) считает это ошибкой, повторяет запрос и после трёх попыток останавливается, хотя импорт курса такого требования не имеет.

## Цель

Пробелы в типах шагов плана не останавливают генерацию — план принимается и показываются предупреждения. Промт плана помогает модели: пример модуля и строка самопроверки.

## Требования

- `parseCourseOutlineText` проверяет только JSON и схему; отсутствие `theory`/`svg`/`quiz` в модуле — предупреждение, без повтора.
- Предупреждения плана видны на странице «Генерация курса» (под планом) и на «Генерации промта» (рядом с принятым планом); промты модулей доступны.
- Промт плана: в system — пример структуры модуля с `theory`, `svg`, `quiz`; в user — строка самопроверки перед финальным напоминанием.
- Промты этапов 2–3 и одношаговый промт не меняются.

## Технические заметки

- `course-generation/` (парсер плана, `generation-stages`), `prompt-generation/` (промт, страница).
- Предупреждения вычисляются `computed` из плана, не хранятся.
