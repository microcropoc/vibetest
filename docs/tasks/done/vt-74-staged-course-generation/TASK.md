# vt-74 — Поэтапная генерация курса через LM Studio

## Контекст

Генерация всего курса одним запросом не помещается в контекст небольших моделей и даёт неверный JSON. Нужна генерация по этапам с повторами.

## Цель

Курс генерируется в три этапа: план (модули и шаги), курс с первым модулем, затем остальные модули по одному. Неверный ответ повторяется; прогресс этапов виден на странице.

## Требования

- Этап 1: модель возвращает план курса по `course-outline.schema.json` (модули и шаги без содержимого).
- Этап 2: course-import DTO с ровно одним (первым) модулем плана; курс сохраняется с новыми UUID.
- Этап 3: модули 2…N по порядку через module-import DTO; в промте указан номер и название модуля из плана; каждый модуль дописывается сразу.
- Retry: до 3 попыток на этап; ошибки предыдущей попытки передаются модели; HTTP/сеть — без повтора.
- После исчерпания попыток — остановка, ошибка и кнопка «Продолжить» с упавшего этапа; «Начать заново».
- На странице: список этапов со статусами и попытками, план курса, ссылка на курс после этапа 2.

## Технические заметки

- `course-generation/`, `prompt-generation/`, `info/`, `tools/generate-course-schema.mts`, `docs/schemas/`.
- Zod-схема плана генерируется из JSON Schema.
