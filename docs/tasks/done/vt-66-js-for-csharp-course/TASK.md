# vt-66 — Флагманский курс «JavaScript для C#-разработчика»

## Цель

Один курс в `docs/courses`: 20 модулей, theory/svg/javascript/regex/quiz, для опытного C#-разработчика. Сборка из модульных JSON + тесты (parse, reference, starter fails, invariants).

## Критерии готовности

- `npm run build:courses` → `javascript-for-csharp.json`
- `ng test --watch=false` зелёный
- Старые sample-курсы удалены
