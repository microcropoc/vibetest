# vt-71 — C# для опытного разработчика: собеседование в Ozon

Флагманский курс `docs/courses/csharp-ozon-interview`: intro + 20 модулей (theory, svg, «Вопросы с собеседования», 4 quiz), .NET 8. Теория собеседования: язык/CLR + backend-стек. Связь с vt-69/vt-70 — ссылками, без дублирования лайвкодинга.

## Критерии готовности

- `docs/courses/csharp-ozon-interview/` + собранный `.json`
- `npm run generate:bundled-courses` — 5 курсов в манифесте
- `ng test --watch=false` зелёный
- Примеры C# проверены compile во временном проекте net8.0 (описано в REPORT)
