# vt-75 — Поэтапные промты на странице «Генерация промта»

## Контекст

В vt-74 генерация курса через LM Studio стала поэтапной (план → курс с модулем 1 → модули 2…N). На вкладке «Генерация промта» есть только одношаговый промт на весь курс, поэтому повторить поэтапный сценарий вручную во внешнем LLM нельзя.

## Цель

На вкладке «Генерация промта» можно скопировать те же промты этапов, что уходят в LM Studio: план курса по `course-outline.schema.json`, затем — по вставленному плану — курс с первым модулем и каждый следующий модуль.

## Требования

- Переключатель режима «Одним промтом» (текущее поведение) / «Поэтапно»; описание курса общее.
- Поэтапно: кнопка копирования промта плана (неактивна при пустом описании).
- Поле для ответа LLM с планом: ответ разбирается как в LM Studio-генерации (сырой JSON или блок ```json), проверяется схемой и семантикой плана; показываются проблемы или план.
- При валидном плане — промты «Курс и модуль 1» и «Модуль k из N» с отдельным копированием и подсказкой, как импортировать результат.
- Каждый промт копируется одним текстом: system, затем user.
- На вкладке «Инфо» — `course-outline.schema.json` с копированием.

## Технические заметки

- `prompt-generation/`, `info/`; переиспользуются `build-staged-generation-messages.ts`, `prepareLlmImportText`, `parseCourseOutlineText`, `generationStepLabel`.
- Промты без structured output (ответ в блоке ```json).
