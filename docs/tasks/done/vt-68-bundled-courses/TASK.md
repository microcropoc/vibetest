# vt-68 — Встроенные курсы из docs/courses

## Цель

При сборке курсы из `docs/courses/*.json` попадают в `public/bundled-courses/` с детерминированными ID (хеш содержимого). При первом запуске и при обновлении приложения устанавливаются новые встроенные курсы. В настройках — кнопка восстановления удалённых встроенных курсов.

## Критерии готовности

- `prebuild` / `prestart` генерируют bundled courses + manifest
- `APP_INITIALIZER` синхронизирует курсы при старте
- Настройки: «Добавить недостающие курсы»
- `ng test --watch=false` зелёный
