# vt-78 — Промт не влезает в контекст модели

## Контекст

Генерация курса через LM Studio на модели с Context Length 8192 (meta-llama-3-8b-instruct) падает на этапе 2 с HTTP 400: `request (8774 tokens) exceeds the available context size (8192 tokens)`. Пользователь видит только «Ошибка API (HTTP 400).» и заранее не знает, что промт не поместится.

## Цель

Промты генерации через API короче; переполнение контекста объясняется по-русски с числами; страница генерации заранее предупреждает, если самый большой промт этапа с запасом под ответ не помещается в Context Length профиля.

## Требования

- В генерации через API (страница «Генерация курса») схемы передаются компактным JSON без отступов. Страница «Генерация промта» и «Инфо» не меняются.
- Ответ API с текстом о переполнении контекста (LM Studio / llama.cpp, OpenAI-подобный) превращается в сообщение «Промт этапа (≈N токенов) не помещается в контекст модели (M). Увеличьте Context Length в LM Studio или выберите модель с бóльшим контекстом.»; без чисел — тот же текст без них. Тело ошибки принимается с `error` строкой и объектом `{ message }`.
- В профиле LLM необязательное поле Context Length (целое, от 512); старые профили читаются без миграции.
- Оценка промта учитывает все три этапа (план, курс с модулем 1, модуль).
- Если в профиле задан Context Length и оценка + запас под ответ (4096) больше него — предупреждение на странице генерации; запуск не блокируется.
