# vt-79 — Ручной поэтапный режим с импортом на странице «Генерация промта»

## Контекст

В поэтапном режиме «Генерации промта» приложение принимает только план. Ответы этапов «Курс и модуль 1» и «Модуль k из N» приходится переносить на вкладку «Импорт», выбирать вид импорта и курс; промт с исправлениями после неверного ответа не формируется. Генерация через LM Studio уже умеет проверять и сохранять каждый этап.

## Цель

Поэтапный режим — мастер: скопировать промт этапа, вставить ответ LLM, проверить и сохранить курс или модуль прямо на странице. Прогресс переживает закрытие страницы.

## Требования

- Проверка и сохранение этапов (курс ровно с одним модулем, дописывание модуля) — общие для генерации через API и ручного режима, без дублирования.
- Одна панель текущего этапа: «Курс и модуль 1», затем «Модуль k из N»; копирование промта (с исправлениями после неверного ответа), поле ответа, «Проверить и сохранить». Попытки не ограничены.
- После сохранения курса — ссылка «Открыть курс», список готовых этапов; после последнего модуля — «Курс готов».
- Описание и план блокируются после сохранения курса.
- Прогресс (описание, ответ с планом, id курса, следующий модуль) хранится в IndexedDB (`settings`), восстанавливается при открытии страницы; «Начать заново» очищает его, курс остаётся.
- Режим «Одним промтом» и вкладка «Импорт» не меняются.

## Технические заметки
